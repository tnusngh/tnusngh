## 🧠 what i'm building

**a game that uses the same hooks as doomscrolling, but makes you smarter instead of emptier.**

- ⚡ **dopamine hits** → surprise rewards, combos, "aha!" moments
- 🧩 **active learning** → every swipe makes you think, not just watch
- 🔁 **built for memory** → brings back what you forget, right before you forget it
- 🧘 **no brainrot** → when your brain is full, the game tells you to rest

> talent is everywhere. exposure isn't. building to fix that, one neuron at a time.
